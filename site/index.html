Local RAG

Ask your own documents.

Point it at a folder. It reads every PDF, Word file, spreadsheet, slide deck and scan inside — then answers questions about them with citations you can click back to the page they came from.

irm https://raw.githubusercontent.com/akashverma-lang/RAG/main/install.ps1 | iex

Paste into PowerShell. Installs to your home folder, takes a few minutes, then opens by itself. Delete the folder to uninstall.

What happens on your machine

Reading, indexing and searching are local. Only the question you type and the passages it selected are sent to the model that writes the answer.

Your files stay put

Nothing is uploaded, copied or synced. The index sits beside your own settings and points back at the originals.

Reads what it finds

PDF, Word, Excel, PowerPoint, CSV, email, HTML and plain text. Scans and photographs go through OCR, so text inside an image is searchable too.

Spreadsheets become queryable

Tables are loaded into SQL, so "how many claims in 2025" is counted across every row rather than guessed from a sample.

Answers carry their source

Every sentence taken from a document is numbered, and the citation opens the file at the right page.

Finds the gaps

Pick a few spreadsheets and it measures where one part of the business is behind another that is already doing better — with the arithmetic shown.

Draws when it helps

A process or a decision comes back as a flowchart, rendered by the page itself with no library and no network call.

Getting started

Four things, once.

  1. Run the command above. It installs a private Python environment in its own folder and starts the app.
  2. A setup screen asks for the folder holding your documents — browse to it, or paste the path.
  3. Paste a free API key. Groq at console.groq.com/keys or Gemini at aistudio.google.com/apikey. Either one is enough.
  4. Press Index files under Manage, wait for it to read the folder, then ask it something.

What it needs

Python3.10 or newer. The installer says so if it is missing.
Memory~400 MB while running. Measured at 307 MB with both local models loaded.
DiskAbout 700 MB for the environment and the two local models, plus the index — roughly a tenth of what it reads.
NetworkNeeded on the first run to download the packages and the embedding model, and thereafter only for the provider that writes answers.
API keyA free Groq or Gemini key. Both have free tiers with rate limits rather than charges.

Why it installs rather than opening in a tab

A page on the web cannot read a folder on your computer — browsers forbid it, and that rule is the reason your files are safe from every other site you have open. A hosted version could only work by having you upload your documents to someone else's server first. This installs instead, so the folder you point at is read where it already lives and never leaves the machine.
